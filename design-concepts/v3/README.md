# دور سوم — آئورا، ویستا، ریتم

نمونه‌های تعاملی. هر جهت یک `index.html` است: تب پایین، برگهٔ ثبت، شمارش مانده، و رسم نمودار. `?shot=1` حالت ثابت برای رندر PNG است. دسکتاپ جداست (`desktop.html`, ۱۴۴۰×۹۰۰). موبایل ۳۹۰×۸۴۴. قلم وزیرمتن. داده همان سارا نادری، ۳۰ مهر ۱۴۰۵، تومان.

این فایل‌ها فقط روی شاخهٔ طراحی هستند. `main`، برچسب `v0-current`، شاخهٔ `v1`، و سایت GitHub Pages دست نخورده‌اند.
